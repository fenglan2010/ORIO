# 模型网关与适配规则

## 设计

先接通国产模型主链路，同时把统一接口、路由和适配规则定死。境外模型只预留适配器，不进入生产默认路径。

对内只暴露统一协议，业务代码不得直接绑定某一厂商 SDK。统一能力至少包括：聊天、工具调用、结构化输出（JSON schema / 等价约束）。

## 厂商适配

| 适配器 | 角色 | 本轮状态 |
| --- | --- | --- |
| DeepSeek（OpenAI 兼容接口） | 国产主模型 | 启用；无密钥时走确定性模拟器，保证离线可演示 |
| Qwen / 通义（OpenAI 兼容接口） | 国产备用 | 适配器预留并可配置，默认备用 |
| OpenAI / ChatGPT | 境外对照 | 适配器预留，默认关闭 |
| Gemini | 境外，长上下文与多模态 | 适配器预留，默认关闭 |
| Grok / xAI | 境外，非收益决策首选 | 适配器预留，默认关闭 |
| MockModel | 本地演示与测试 | 始终可用 |

## 必须实现的规则

1. **统一协议**：所有适配器输入输出一致，包含模型名、任务类型、是否允许工具调用、结构化结果、用量与错误码。
2. **按任务路由，不按厂商写业务**：任务类型示例：`analysis`、`pricing_strategy`、`review_reply`、`assistant_chat`、`vision_or_longdoc`。
3. **超时、限流、失败自动降级**：主模型失败则切备用国产模型，再失败则切 Mock 并明确告知“当前为降级结果”。
4. **境外模型默认关闭**，需在配置中单独授权开启。
5. **关键动作禁出境**：`pricing_strategy`、`review_reply` 以及任何将导致调价/回复/执行的调用，即使境外模型已开启，也不得路由到境外适配器。
6. **审计**：每次调用记录厂商、模型、任务类型、租户/酒店、是否出境、是否降级、时间与结果状态；不得把完整密钥写入日志。

## 能力分工

- 大模型：理解、归因说明、策略草案、评价回复、对话
- 自研计算（规则 + 统计模型，本轮用可解释的启发式即可）：需求预测、价格区间、约束校验（最低价、竞对带、库存）
- 大模型不得直接输出一个不可复核的最终执行价；必须给出建议区间、推荐值、理由、置信度，交由人审
