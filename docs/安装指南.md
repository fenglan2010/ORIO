# OIRO 安装指南

本指南面向两条主线：**官方桌面安装包（Windows 优先）**与**开源从源码本地运行**。云上 Compose/K8s 为可选历史路径，见文末。

## 一、环境要求

| 组件 | 从源码运行 | 桌面正式包 |
|------|------------|------------|
| 操作系统 | Windows / macOS / Linux | Windows 10+（日常推荐） |
| Python | 3.11+ | 安装包内置或由 Electron 调用本机 venv |
| Node.js | 18+（仅构建前端） | 开发者构建时需要 |
| 数据库 | SQLite（默认，零配置） | 用户目录下 SQLite |

## 二、开源从源码运行（无需安装密钥）

```bash
git clone <your-repo-url> oiro
cd oiro
make dev
```

- 前端：http://127.0.0.1:5173  
- 后端：http://127.0.0.1:8000  
- 默认账号：`admin` / `admin123`  
- 环境变量 `OIRO_DISTRIBUTION` 默认为 `source`，**不启用**安装密钥门闩。

单进程桌面式（后端同时托管已构建前端）：

```bash
bash scripts/run-desktop-source.sh
# 构建 dist 后以 OIRO_STATIC_ROOT=frontend/dist 启动，浏览器打开 http://127.0.0.1:8000
```

## 三、官方桌面安装包

1. 在 **Windows** 上克隆仓库，创建 Python 虚拟环境并安装 `backend/requirements.txt`。
2. 执行 `desktop/scripts/build-windows.ps1` 生成 NSIS 安装包（需本机 Node 与代码签名证书方可得到受信任安装程序）。
3. 安装或首次启动时输入 **应用安装密钥**（格式 `OIRO-XXXX-XXXX-XXXX`）。
4. 安装包设置 `OIRO_DISTRIBUTION=packaged`；数据与 SQLite 位于用户数据目录下的 `oiro/data/`。

> Linux/macOS 云构建环境**不产出**已签名 `.exe`；仓库提供 `desktop/` 脚手架与可复现 Windows 构建脚本。

## 四、开发调试桌面壳

```bash
# 终端 1
make dev

# 终端 2
cd desktop && npm install && OIRO_DEV_URL=http://127.0.0.1:5173 npm start
```

模拟正式包门闩：

```bash
export OIRO_DISTRIBUTION=packaged
export OIRO_INSTALL_KEY_ACCEPT=OIRO-TEST-0000-0000-0000
# 重启后端后访问前端，将跳转 /install 激活页
```
